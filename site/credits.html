← OCARINA OF TIME TOGETHER

A shared adventure.

Original The Legend of Zelda: Ocarina of Time game, characters, music and assets © Nintendo. This is an unofficial fan project with no Nintendo affiliation.

The native engine is Ship of Harkinian by HarbourMasters, built on the Zelda decompilation community’s work. Browser support comes from zalo’s Emscripten port. Multiplayer player, inventory and quest synchronization use the Anchor implementation by garrettjoecox and contributors. PeerJS connects the two browsers. Shared enemy combat adapts OOT-True-Co-op by bghill95, with browser transport, collision validation, targeting and lifecycle corrections for this build.

This project adds private two-player rooms, a browser-hosted Anchor relay, shared team-death rules, automatic game startup, mobile interface and independent health displays. The native game is compiled from the pinned source with the project’s C++ hooks.
